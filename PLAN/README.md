# Versioned LOADOUT planning snapshots

These files preserve the LOADOUT planning bundle so collaborators can review the current product direction and the decisions that led to the first public-site demo. Plans 00–10 are the canonical planning set; check each document's status and use the newest user-approved decisions when plans disagree.

Plans 00–08 hold product, economy, UI, migration, workflow, and ecosystem context. Plan 09 records the homepage port/redesign; Plan 10 records the RSVP, motion, content and desktop-width refinement and its verification.

`LOADOUT_MASTER_PLAN_v4.md` is retained as historical context and may contain superseded decisions. `PROMPT_00_GATHER_HACKCLUB_YSWS_CONTEXT.md`, `PROMPT_01_BOOTSTRAP_AUDIT_AND_PUBLIC_HOMEPAGE.md`, and `PROMPT_LOADOUT_BOOTSTRAP_AND_HOMEPAGE.md` are preserved inputs. Prompt 00 is a research prompt; Prompt 01 was executed for the initial bootstrap; do not rerun either prompt as a current task. The short bootstrap prompt is superseded by the canonical plans and current repository state. These artifacts do not override current user instructions or plans 00–10.

Application file paths in the plan responsibility maps are relative to this Git repository; older loadout/ prefixes refer to this checkout. The workspace-root design-system snapshot is LOADOUT_DESIGN_SYSTEM.md. Design images are indexed in `docs/design/references/README.md`.
