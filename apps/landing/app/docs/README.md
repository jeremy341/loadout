# LOADOUT public draft Docs

Reviewed public source lives in `content/docs/*.md`. The filename defines the slug; validated frontmatter defines title, description, group, order and draft status. The server loader builds static pages and the public-only search index. ReactMarkdown/GFM rendering and shared heading IDs replace the old guide objects.

Keep internal workflow, architecture, plans, budgets and source audits out of this renderer/search. The homepage FAQ stays independent.
