# LOADOUT design references

This folder keeps the pixel-art icon sources used to build the runtime sprites. Concept screenshots and UI explorations were removed on 2026-10-20; they were historical design images, not product facts, and remain in Git history.

## Pixel-art icon sources

The source-to-runtime mapping and renamed source files are in [`../asset-catalog.md`](../asset-catalog.md).
- [`2026-10-06/final-pixel-icons/source/`](2026-10-06/final-pixel-icons/source/) - the 42 original, semantically renamed pixel-art PNGs; source pixels and transparency were preserved.

These are build sources, not product decisions. Do not add new concept PNGs here; newer design work belongs in a design brief or the parent workspace. Use current application code, canonical plans, and the design system for shipped behavior and product facts.
