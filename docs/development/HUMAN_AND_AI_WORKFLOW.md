## People and AI work the same way

Inspect and preserve local work, post the authorized kickoff, use a temporary branch, and report actual verification. AI use does not exempt anyone from review or publication checks.

Give an AI the task, audience, explicit exclusions and relevant plan/brief. It should read the owning sources, not execute old bootstrap prompts or treat screenshots as policy.

Agents use GPT-6 Luna at medium unless the owner asks otherwise. UI skills improve implementation quality without authorizing extra features.

## When the task is finished

Link the PR and summarize the changed behavior, checks, screenshots and remaining public-data gates. Distinguish local implementation, merged code and verified Production.

Use [CONTENT_AUTHORING.md](CONTENT_AUTHORING.md) for Docs changes and [RIVET_HANDOFF.md](RIVET_HANDOFF.md) for the separate bot integration.
